Pagina originale

He's funny. He dances. He smokes crack and gets high. He's the swaggest triangle our universe has ever known.

This game is a 3D platformer with elements of parkour, mazes, jumping and exploring. You play as the swag triangle, which is the talking Triforce from The Legend of Zelda that became a meme in 2007 thanks to YouTube user DancingTriforce.

Note: the game is currently in active development. It may and will have imperfections, bugs, and lack a proper ending. See the devlog for more info.

Install instructions

  • Windows (x86/x64):

Download the Windows archive of the game and extract it to a folder on your PC. Then you should be able to start the .exe file and play no problem.

  • Linux (x64):

Download the Linux archive of the game and extract it to a folder on your PC. You should be able to start the executable file and play the game, but if it doesn't work check that the file has executable permissions (usually in the file properties).

  • Android:

Download the .apk file of the game and install it, then open the game. Please note that I've not released the Android build as a mobile build, but more of a desktop build for PCs running Android (Chromebook for example). I tried it on an actual phone and the performance is far from playable. Also, for now the game has no touch controls, so even on Android you need an external Bluetooth or USB keyboard for moving and eventually a mouse for rotating the camera (although you can move your finger on the screen to do that).
