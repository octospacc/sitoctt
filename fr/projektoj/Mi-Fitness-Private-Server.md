** MI Fitness Private Server ** est une expérience d'expérience d'information inversée pour la réimplément à partir de zéro une API et un serveur CDN entièrement indépendant pour l'application Xiaomi _mi Fitness_, pour remplacer celle officielle, afin de déverrouiller plus de fonctionnalités et, À l'avenir, garantir le fonctionnement de l'application en confidentialité complète et sans dépendance au serveur officiel.

Toutes les informations et le code source sont disponibles sur GIT:

* https://gitlab.com/octospacc/mi-fitness-private-sser
* https://github.com/octospacc/mi-fitness-private-server
* https://gitea.it/octospacc/mi-fitness-private-server
