** MI Fitness Private Server ** es un experimento del experimento de información inversa para reimplegar desde cero una API y un servidor CDN completamente independiente para la aplicación Xiaomi _MI Fitness_, para reemplazar la oficial, para desbloquear más características y, En el futuro, garantice la operación de la aplicación en total privacidad y sin adicción al servidor oficial.

Toda la información y el código fuente están disponibles en GIT:

* https://gitlab.com/octospacc/mi-fitness-private-ser
* https://github.com/octospacc/mi-fitness-private-server
* https://gitea.it/octospacc/mi-fitness-private-server
