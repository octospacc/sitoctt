About this extension
This add-on enables offline caching on any web site or app, even those that aren't developed with this feature in mind, allowing use when Internet isn't available. This works by injecting a dedicated Service Worker on any host you choose via the popup menu, so it has the benefit of using an established and well-tested web technology to do its job. Due to Service Workers limitations, keep in mind that this only works on HTTPS sites and outside of private browsing mode.
Developer comments
Currently, the add-on can't delete cached data or the installed Service Workers when it gets uninstalled. If you need to uninstall it, please open the pop-up menu on the sites where you enabled Offline Caching to disable it and purge the cache. (Some mitigation to this issue will be implemented in the future.)
