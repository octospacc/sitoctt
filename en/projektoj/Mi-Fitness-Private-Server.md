** Mi Fitness Private Server ** is an experiment of Reverse-enignering experiment for re-reimplement from scratch an entirely independent API and CDN server for the Xiaomi app _Mi Fitness_, to replace the official one, in order to unlock more features and, in the future, guarantee the operation of the app in complete privacy and without addiction to the official server.

All information and source code is available on GIT:

* https://gitlab.com/octospacc/mi-fitness-private-Sser
* https://github.com/octospacc/mi-fitness-private-Server
* https://gitea.it/octospacc/mi-fitness-private-Server
